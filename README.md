# NeoMundi × ASRO — Round 2 Methodology Protocol

## Purpose

This private repository documents Round 2 of the NeoMundi × ASRO methodological collaboration.

The purpose of this round is to examine how NeoMundi runtime observations can be documented, interpreted and bounded in a way that preserves clear distinctions between:

* measurement;
* observation;
* interpretation;
* attestation;
* governance authority;
* downstream action.

## Core Question

Can a runtime measurement record remain useful for governance, audit and reconstruction without overstating what the measurement itself proves?

## Scope

Round 2 is a methodological and non-production exercise.

It does not involve:

* customer data;
* proprietary prompts or outputs;
* live production decisions;
* legal certification;
* delegated governance authority;
* automatic execution control.

## Roles

**NeoMundi** provides structured runtime observation records, including behavioral stability, coherence, risk signals, measurement coverage and documented limitations.

**ASRO** provides methodological review on proof discipline, attestation boundaries, authority separation, contribution integrity and the conditions under which a record can remain interpretable and reconstructible.

Neither party’s contribution should be interpreted as transferring operational authority to the other.

## Expected Deliverables

Round 2 aims to produce:

1. a clarified measurement and attestation boundary;
2. a reviewed set of methodological questions and findings;
3. a documented distinction between observed state, interpretation and authority;
4. a traceable review record;
5. a short synthesis of conclusions, limitations and next steps.
